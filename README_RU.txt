BINANCE COIN SCANNER PRO — Android-проект, версия 1.0

Что уже предусмотрено в исходниках:
- нативный Android-интерфейс с тёмной темой;
- загрузка публичных спотовых данных Binance без API-ключа;
- отбор ликвидных USDT-пар и анализ до 35 наиболее ликвидных;
- рейтинг на основе импульса 1ч/4ч, EMA 9/21, RSI и относительного объёма;
- отдельная вкладка списка мемкоинов;
- локальное уведомление после сканирования при обнаружении рейтинга 80+;
- без автоматических сделок и без доступа к средствам пользователя.

КАК СОБРАТЬ APK:
1. Установи Android Studio с официального сайта https://developer.android.com/studio
2. Распакуй архив проекта.
3. В Android Studio выбери Open и укажи папку BinanceCoinScannerPRO.
4. Дождись Gradle Sync и установки Android SDK Platform 35 (если Android Studio предложит).
5. Для проверки нажми Run и выбери Android-телефон с включённой USB debugging.
6. Для APK выбери Build > Build Bundle(s) / APK(s) > Build APK(s).
7. Готовый debug APK будет в app/build/outputs/apk/debug/app-debug.apk.

Требования: Android Studio, Android SDK, JDK 17. В этом архиве исходный проект; APK ещё не собран в данной среде, поскольку Android SDK/Gradle не установлены.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ:
- рейтинг эвристический и не является прогнозом или гарантией доходности;
- сканирование выполняется по нажатию кнопки; постоянная фоновая работа пока не реализована;
- торговля через API не реализована намеренно. Перед её добавлением нужны отдельные тесты, paper trading и защита ключей API. Никогда не включать право вывода средств для торгового ключа.
- Binance может ограничивать запросы; при ошибке сети повтори сканирование позже.
