КАК СОБРАТЬ APK ТОЛЬКО С ТЕЛЕФОНА (через GitHub Actions)

Важно: Android Studio на телефон устанавливать не нужно. APK будет собираться на облачном компьютере GitHub.

1. Открой в браузере https://github.com и создай бесплатный аккаунт или войди.
2. Создай новый репозиторий (New repository), назови его BinanceCoinScannerPRO. Для простоты можно выбрать Public; не добавляй README, .gitignore или лицензию на этапе создания.
3. Распакуй BinanceCoinScannerPRO_source.zip приложением «Файлы»/архиватором на телефоне.
4. В репозитории нажми Add file → Upload files. Загрузи содержимое папки BinanceCoinScannerPRO, сохранив структуру каталогов. Включи папку .github/workflows/build-apk.yml: она нужна для облачной сборки. Если Android/браузер не показывает скрытую папку .github, создай её в репозитории через Add file → Create new file и укажи путь .github/workflows/build-apk.yml, затем вставь содержимое одноимённого файла из архива.
5. Нажми Commit changes.
6. Открой вкладку Actions в репозитории. Если GitHub попросит разрешить Actions, подтверди.
7. Выбери workflow «Build Binance Coin Scanner PRO APK» и нажми Run workflow. Если workflow уже запустился после Commit changes, можно открыть этот запуск.
8. Дождись зелёной отметки Success, открой запуск и найди раздел Artifacts внизу страницы.
9. Скачай BinanceCoinScannerPRO-debug-apk.zip, распакуй его на телефоне — внутри будет app-debug.apk.
10. Нажми APK и разреши установку из этого источника, если Android спросит. Устанавливай только APK, который собрался в твоём собственном репозитории.

Если сборка упадёт: открой запуск Actions, нажми на шаг Build debug APK и скопируй сюда последние строки ошибки. Я помогу исправить.

Безопасность: не добавляй API-ключи Binance в исходники или репозиторий. Текущая версия использует публичные рыночные данные и не выполняет сделки. Рейтинг не гарантирует прибыль.
